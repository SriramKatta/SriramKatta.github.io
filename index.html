About

I work on high-performance scientific computing at NHR@FAU (National High-Performance Computing, Friedrich-Alexander-Universität Erlangen-Nürnberg), helping researchers run simulation codes fast — and portably — on modern GPU hardware.

My work sits at the intersection of GPGPU programming and computational physics: lattice Boltzmann and smoothed-particle hydrodynamics solvers, sparse iterative solvers, multi-GPU benchmarking, and the parallel IO/tooling around large simulations. I care about GPU code that doesn't get locked to one vendor — which is why I built a CUDA/HIP abstraction runtime so the same C++ powers both ecosystems.
