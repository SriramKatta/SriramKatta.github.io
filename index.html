# about

Hi, I'm Sriram.

I work on high-performance scientific computing at NHR@FAU (National High-Performance Computing, Friedrich-Alexander-Universität Erlangen-Nürnberg), where I help researchers get simulation codes running fast — and running portably — on modern GPU hardware.

My work sits at the intersection of GPGPU programming and computational physics: lattice Boltzmann and smoothed-particle hydrodynamics solvers, iterative sparse linear solvers like conjugate gradient, multi-GPU benchmarking, and the IO/tooling glue (MPI readers, HDF5) that holds large simulations together.

I care about writing GPU code that doesn't get locked to one vendor — which is why I built a CUDA/HIP abstraction runtime so the same C++ powers both ecosystems.
